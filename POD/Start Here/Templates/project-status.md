# Project Status

## How to use this doc

What is in flight **now**. Overwrite in place when things change — this is not a history log.

**Now:** Every active Backlog row at Priority `Now` (multiple rows OK across agents). Use the table below.

Do **not** add **Next** or **Later** sections or tables here. Non-Now work stays in the Backlog; drafted plans and specs stay in `Future Work/`.

**Notes column:** When useful, end with a brief "Last worked:" line (state, decision, or stop point) so the next session can resume without the prior chat.

**Agents:** One row per agent role in `Agent Instructions/`. Add a row when a role is created; remove it when a role is retired. Refresh your row when winding down a session (see `Developer Documentation/Reference/Session Wind-Down.md`).

**Plans:** Plans and specs for `in progress` rows live in `In Progress/`; everything else stays in `Future Work/`.

Not this doc: shipped history (Changelog), the full open backlog (Backlog), product goals and rules (Project Overview), how the app is built and coded (Architecture, Implementation Principles).
